# Obsidian Agent Vault

This repository is the **dedicated Obsidian-style knowledge base** used by [Fast Agentic AI](https://github.com/bossayan9999/fast-agentic-ai).

- Add any `.md` notes here
- The agent searches these notes during the Memory & Context stage
- You can also write notes back via the app's `/api/memory` endpoint
